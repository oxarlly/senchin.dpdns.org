(1)
$\rho = \frac{p}{gh} = \frac{4 \times 10^2\ \text{Pa}}{10\ \text{N/kg} \times 0.04\ \text{m}} = 1.0 \times 10^3\ \text{kg/m}^3$

(2)
$F = pS = 4 \times 10^2\ \text{Pa} \times 8 \times 10^{-3}\ \text{m}^2 = 3.2\ \text{N}$

(3)
$G_{\text{液}} = F = 3.2\ \text{N}$
$F_{\text{桌}} = G_{\text{容}} + G_{\text{液}} = 4\ \text{N} + 3.2\ \text{N} = 7.2\ \text{N}$
$p_{\text{桌}} = \frac{F_{\text{桌}}}{S} = \frac{7.2\ \text{N}}{8 \times 10^{-3}\ \text{m}^2} = 900\ \text{Pa}$
